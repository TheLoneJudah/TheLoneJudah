# Ajibade Praise Titus

Mechatronics engineer and Master's student in IT at Miva Open University, building practical AI for Nigerians.

## Projects

### [Cul-Text](https://cul-text.vercel.app)
A culturally aligned AI for Nigerians. It answers questions and writes messages, then checks each answer against a Nigerian knowledge base covering Yoruba, Igbo, Hausa and Efik contexts. This is my Master's research project.

**Built with:** Python, FastAPI, retrieval-augmented generation, Chroma, Supabase, JavaScript, Render and Vercel

[Try it live](https://cul-text.vercel.app) · The source code is private for now.

### [WetinLast](https://wetinlast.vercel.app)
An online car parts market that connects mechanics, buyers and car owners. Built for the Cowrywise innovation challenge.

**Built with:** TypeScript

[Try it live](https://wetinlast.vercel.app) · The source code is private.

### RRC EDI Generator
A tool to help oil and gas companies in Texas generate EDI files for G-10 and W-10 forms.

**Built with:** Python · The source code is private.

### [Voice-Controlled Wheelchair](https://github.com/TheLoneJudah/voice-controlled-wheelchair)
A retrofitted wheelchair for children with motor impairments, driven by voice commands through an Android app or by a joystick. This was my B.Eng. final year project in Mechatronics Engineering at Bells University of Technology, Ota.

**Built with:** C++, Arduino, NodeMCU and MIT App Inventor

### [PostgreSQL Bootcamp](https://github.com/TheLoneJudah/postgres-bootcamp)
